# سجل التحصيل اليومي

تطبيق ويب صغير (PWA) لتسجيل بيانات العملاء وتتبع المبالغ المرسلة والمحصّلة يوميًا، يعمل بالكامل على المتصفح بدون خادم — كل البيانات محفوظة محليًا في متصفحك (`localStorage`).

## المزايا

- إضافة العملاء مع بياناتهم: الاسم، المحل، رقم المكنة، المنطقة، الموقع، الهاتف.
- تسجيل المعاملات اليومية: إرسال مبلغ، تحصيل جزئي، تحصيل كامل بضغطة واحدة، وتعديل أي معاملة.
- إحصائيات مدمجة في الهيدر: إجمالي اليوم، المحصّل، المتبقي.
- فلتر "عليهم متأخرات" لعرض العملاء المتأخرين فقط.
- جولة التحصيل: ترتيب العملاء حسب أقرب موقع لك.
- متابعة المتأخرات لكل عميل حسب كل معاملة.
- تصدير تقارير Excel لكل عميل أو لفترة زمنية (يتحمّل مكتبة Excel تلقائيًا عند الحاجة).
- نسخة احتياطية: تنزيل واستعادة كاملة للبيانات.
- **وضع نهاري/ليلي**: زرّ ☀️ / 🌙 أعلى الصفحة للتبديل بين الوضعين، مع حفظ التفضيل.
- يعمل كتطبيق تثبيت (PWA): يعمل دون اتصال بالإنترنت.

## الملفات

| الملف | الوصف |
|------|-------|
| `index.html` | التطبيق بالكامل (التصميم + المنطق) |
| `sw.js` | Service Worker للعمل دون اتصال |
| `manifest.json` | بيانات التطبيق القابل للتثبيت |
| `icon-192.png` / `icon-512.png` | أيقونات التطبيق |
| `previews/` | نسخ تجريبية لتصاميم أخرى (غير مطلوبة للتشغيل) |

## التشغيل محليًا

بأي سيرفر ثابت:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الرفع على GitHub

من داخل مجلد المشروع:

```bash
git init
git add .
git commit -m "سجل التحصيل اليومي - تصميم Dark Pro مع وضع نهاري/ليلي"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

يمكنك أيضًا إنشاء الريبو من سطر الأوامر (إن كنت مسجّلًا في `gh`):

```bash
gh repo create <repo-name> --public --source . --remote origin --push
```

## النشر مجانًا (GitHub Pages)

بعد الرفع، من إعدادات الريبو:

1. Settings → Pages.
2. من "Source" اختر `main` وفولدر `/root`.
3. Save، ثم افتح الرابط `https://<username>.github.io/<repo-name>/`.

> ملاحظة: لا يوجد أي اتصال بخادم — بياناتك لا تخرج من متصفحك إطلاقًا.
